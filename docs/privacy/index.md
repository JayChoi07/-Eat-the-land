# 땅따먹기 개인정보처리방침

시행일: 2026-09-30

땅따먹기(이하 "앱")는 걸어서 지나간 곳을 지도에 내 땅으로 표시하는 산책 앱입니다. 이 문서는 앱이 어떤 정보를 왜 다루는지 설명합니다.

## 1. 수집하는 정보

| 정보 | 수집 시점 | 쓰는 곳 |
|---|---|---|
| 닉네임 | 처음 시작할 때, 설정에서 바꿀 때 | 지도의 땅 주인 표시, 랭킹 |
| 위치(정밀) | **산책 중일 때만** | 지나간 약 50 m 육각형 칸을 내 땅으로 기록, 산책 거리 계산 |
| 산책 기록(시작·종료 시각, 칸 수, 거리) | 산책을 끝낼 때 | 산책 기록 보관 |
| 익명 계정 식별자 | 처음 시작할 때 자동 생성 | 내 땅·닉네임·기록을 한 계정으로 묶기 |

- 이름, 이메일, 전화번호, 연락처, 사진은 수집하지 않습니다.
- 지나간 경로 자체(좌표의 연속)는 서버에 저장하지 않습니다. 서버에는 **어느 칸을 언제 밟았는지**만 남습니다.
- 광고 식별자를 수집하지 않으며 광고를 싣지 않습니다.

## 2. 위치 정보

- 위치는 "산책 시작" 을 누른 뒤부터 "산책 종료" 를 누를 때까지만 읽습니다.
- 산책 중에는 화면을 꺼도 위치를 읽습니다. 이때 알림 창에 산책 중임을 계속 표시합니다.
- 산책 중이 아닐 때는 위치를 서버로 보내지 않습니다.

## 3. 다른 사용자에게 보이는 정보

- 내 닉네임과 내가 가진 칸 수는 랭킹에서 다른 사용자에게 보입니다.
- 내가 가진 칸을 다른 사용자가 누르면 내 닉네임과 그 칸을 밟은 시각이 보입니다.

## 4. 보관과 처리 위탁

- 정보는 Google 의 Firebase(Authentication, Cloud Firestore)에 저장하며, 기기와 서버 사이의 전송은 암호화됩니다.
- 지도는 카카오맵 SDK 로 표시합니다. 지도를 불러올 때 카카오의 정책에 따라 기기 정보와 지도 요청 정보가 카카오로 전송될 수 있습니다.
- 위 목적 밖으로 제3자에게 정보를 팔거나 넘기지 않습니다.

## 5. 보관 기간과 삭제

- 정보는 계정을 삭제할 때까지 보관합니다.
- **앱 안에서 삭제:** 설정 → 계정 삭제. 닉네임과 계정 정보가 삭제됩니다.
- 계정을 삭제해도 내가 가졌던 칸은 지도에 남고, 주인은 "떠난 사람" 으로 표시됩니다. 닉네임과의 연결은 끊깁니다. 다른 사용자가 그 칸을 밟으면 그 사용자의 땅이 됩니다.
- 계정은 기기에만 저장됩니다. 앱을 지우거나 기기를 바꾸면 같은 계정으로 다시 들어올 수 없습니다.
- **앱을 이미 지운 경우:** 아래 연락처로 닉네임을 알려 주시면 계정 정보를 삭제합니다.

## 6. 어린이

앱은 만 14세 미만 어린이를 대상으로 하지 않습니다.
